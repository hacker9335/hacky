# Hacky
A custom mechanical macropad built on the Seeed XIAO RP2040, running QMK/VIA firmware.
Features

Seeed XIAO RP2040 — QMK/VIA compatible
4 mechanical keys
2 rotary encoders (volume/scroll/custom functions)
OLED display for
3D printed 3-part case with an angled stand

Bill of Materials

| Component | Qty |
|-----------|-----|
| RP2040 (XIAO) | 1 |
| Switches | 4 |
| Encoders | 2 |
| OLED| 1 |
| PCB | 1 |
